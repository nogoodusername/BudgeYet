# Running the **fam‑ex** Front‑End (Compose Multiplatform)

The project supports two native targets:

* **Android** – via the Gradle wrapper and an Android Virtual Device (AVD) or a physical device.
* **iOS** – via Xcode (real iPhone connected to the Mac or an iOS simulator).

Both workflows assume you are in the repository root:

```
/Users/kshitijnagvekar/Projects/Personal/fam-ex/frontend
```

---

## 📱 Android – Build & Run

### 1️⃣ Prerequisites

| Item | How to verify / install |
|------|------------------------|
| **Java 21 (JBR)** – used by the Gradle wrapper | `"$JAVA_HOME/bin/java" -version` (should show `openjdk version "21.0.10"`). The wrapper is already configured to use the JBR shipped with Android Studio. |
| **Android SDK** | `echo $ANDROID_HOME` → should point to `~/Library/Android/sdk`. |
| **Platform‑tools (adb, emulator)** | `$ANDROID_HOME/platform-tools/adb version` |
| **Gradle wrapper** (binary `./gradlew`) | `./gradlew -v` – should report Gradle 8.4. |
| **AVD** (optional) | `emulator -list-avds` – you already have `Medium_Phone`. |

If you prefer a **physical device**, enable **Developer options → USB debugging** and connect it via USB.

### 2️⃣ Start an Android emulator (optional)

```bash
export ANDROID_HOME=~/Library/Android/sdk
export PATH=$ANDROID_HOME/emulator:$ANDROID_HOME/platform-tools:$PATH
emulator -avd Medium_Phone -no-window &   # background launch
adb wait-for-device
```

### 3️⃣ Build & install the app

From the **frontend** directory:

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
export ANDROID_HOME=~/Library/Android/sdk
export PATH=$ANDROID_HOME/platform-tools:$PATH

# Build + install on the currently attached device (emulator or real phone)
./gradlew :composeApp:installDebug
```

> **What happens**
> * Gradle resolves dependencies, compiles the Kotlin Multiplatform source, and produces `composeApp-debug.apk`.
> * The APK is automatically installed on the selected device.

### 4️⃣ Launch the app (if not auto‑started)

```bash
adb shell am start -n com.famex/com.famex.MainActivity
```

You should see the **fam‑ex** UI on the device/emulator.

### 5️⃣ Verify the process (optional)

```bash
adb shell pidof com.famex   # prints the PID of the running process
```

## 🍎 iOS – Build & Run

### 1️⃣ Prerequisites

| Item | How to verify / install |
|------|------------------------|
| **Xcode** (≥ 15) | `xcode-select -p` → should point to `/Applications/Xcode.app`. |
| **Command Line Tools** | `xcode-select --install` (if not already present). |
| **iOS device** (connected) **or** **Simulator** | `xcrun simctl list devices` – shows available simulators. |
| **CocoaPods** (optional, for certain dependencies) | `pod --version`. |

> **Note:** The iOS Xcode project lives at
> `[iosApp](/Users/kshitijnagvekar/Projects/Personal/fam-ex/frontend/iosApp/iosApp.xcodeproj)`.

### 2️⃣ Open the Xcode project

```bash
open iosApp/iosApp.xcodeproj
```

Xcode will load the **ComposeApp** scheme (generated by the Gradle Multiplatform plugin).

### 3️⃣ Configure signing (once)

1. Select the **iosApp** target in the project navigator.
2. In the **Signing & Capabilities** tab, enable **Automatically manage signing**.
3. Choose your personal/team Apple ID from the **Team** dropdown.
4. Xcode will create a Development provisioning profile for the connected device or simulator.

### 4️⃣ Choose a run destination

* **Physical iPhone** – Plugged‑in iPhone appears in the device list (e.g., “John’s iPhone”).
* **Simulator** – Click the device selector and pick a simulator (e.g., *iPhone 15 Pro (iOS 17.5)*).

If you prefer to launch a simulator from the terminal:

```bash
# List available simulators
xcrun simctl list devices available

# Boot a specific simulator (replace the UUID with the one you want)
SIMULATOR_UUID="YOUR_SIMULATOR_UUID"
xcrun simctl boot "$SIMULATOR_UUID"
open -a Simulator   # brings the Simulator UI forward
```

### 5️⃣ Build & Run

Press **⌘ R** (or click the *Run* button). Xcode will:

1. Invoke the Gradle task `linkDebugFrameworkIosArm64` (or the appropriate SDK for the selected device).
2. Build the Kotlin/Native binary, embed it into an Xcode app bundle.
3. Install the bundle on the selected device/simulator.
4. Launch `MainActivity` (iOS entry point is `MainActivity` in the same package `com.famex`).

You should now see the same UI that runs on Android.

### 6️⃣ Command‑line alternative (simulator only)

If you prefer a pure CLI flow:

```bash
# Build the iOS framework for the simulator
./gradlew :composeApp:linkDebugFrameworkIosX64

# The framework is placed under
#   composeApp/build/bin/iosX64/debugFramework/composeApp.framework

# Create an .app bundle (Xcode can do this automatically, but the below is a minimal manual way)
# 1. Create a simple stub Xcode project that links the framework – the project already exists in iosApp.
# 2. Build it via xcodebuild:

xcodebuild -project iosApp/iosApp.xcodeproj \
    -scheme iosApp \
    -configuration Debug \
    -sdk iphonesimulator \
    -destination 'platform=iOS Simulator,name=iPhone 15,OS=latest' \
    clean build

# Install on the booted simulator:
 xcrun simctl install booted iosApp/build/Debug-iphonesimulator/iosApp.app
 xcrun simctl launch booted com.famex
```

> The CLI method is handy for CI pipelines; for everyday development the Xcode UI is faster.

### 7️⃣ Sideload with SideStore (physical device, no developer account)

If you have [SideStore](https://sidestore.io) installed on your iPhone and want to avoid Xcode's 7-day re-signing limitation, build an unsigned `.ipa` and install it via SideStore:

```bash
# Build the .app for a physical device (unsigned — SideStore re-signs)
export JAVA_HOME=$(/usr/libexec/java_home)
xcodebuild -project iosApp/iosApp.xcodeproj \
    -scheme iosApp \
    -configuration Debug \
    -destination 'generic/platform=iOS' \
    -derivedDataPath build/DerivedData \
    CODE_SIGNING_ALLOWED=NO \
    CODE_SIGN_IDENTITY=- \
    build

# Package into .ipa
rm -rf /tmp/famex-ipa
mkdir -p /tmp/famex-ipa/Payload
cp -R build/DerivedData/Build/Products/Debug-iphoneos/iosApp.app /tmp/famex-ipa/Payload/
cd /tmp/famex-ipa && zip -qry "$OLDPWD/build/famex.ipa" Payload/ && cd -
```

**Install steps:**
1. AirDrop `frontend/build/famex.ipa` to your iPhone.
2. Open SideStore on the phone → tap the IPA → **Install**.
3. If prompted, enable **Developer Mode** (Settings → Privacy & Security → Developer Mode) and trust the certificate (Settings → General → VPN & Device Management).

> **Note:** The Xcode project requires minimum iOS 17.0. To change it, update `IPHONEOS_DEPLOYMENT_TARGET` in both Debug and Release configurations of `iosApp/iosApp.xcodeproj/project.pbxproj`.

You now have a complete, reproducible guide for **building and running** the `fam‑ex` Compose Multiplatform frontend on **both Android and iOS** platforms—whether on a physical device or an emulator/simulator.
