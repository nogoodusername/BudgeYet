# iOS release — unsigned .ipa for SideStore

Builds the iOS app **unsigned** (SideStore re-signs it on the device) and packages it into a `.ipa` for AirDrop + SideStore install. Use this for sideloading on a physical iPhone without a paid developer account / Xcode's 7-day re-signing.

## 1. Verify version first

```bash
cat frontend/version.properties     # e.g. VERSION_NAME=1.1.1 / VERSION_CODE=4
```

iOS reads this via `frontend/iosApp/Config.xcconfig` (regenerated by `scripts/sync_version.sh`, which `bump_version.sh` runs). If `Config.xcconfig`'s `MARKETING_VERSION`/`CURRENT_PROJECT_VERSION` ever drift from `version.properties`, run `./scripts/sync_version.sh` first — the CI `version-drift-check` job fails otherwise.

## 2. Build the unsigned .app for a physical device

```bash
cd frontend
export JAVA_HOME=$(/usr/libexec/java_home)
xcodebuild -project iosApp/iosApp.xcodeproj \
    -scheme iosApp \
    -configuration Debug \
    -destination 'generic/platform=iOS' \
    -derivedDataPath build/DerivedData \
    CODE_SIGNING_ALLOWED=NO \
    CODE_SIGN_IDENTITY=- \
    build
```

- `-destination 'generic/platform=iOS'` builds for a physical device (arm64), not a simulator.
- `CODE_SIGNING_ALLOWED=NO` + `CODE_SIGN_IDENTITY=-` produce an **unsigned** `.app` — exactly what SideStore needs to re-sign. Do **not** add signing flags or the app can't be sideloaded.
- The Xcode build phase invokes Gradle to link the Kotlin/Native framework — any recent JDK (17+) works; if it fails at that phase, export `JAVA_HOME` to JDK 17 (`/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home`) or the Android Studio JBR.
- Output: `frontend/build/DerivedData/Build/Products/Debug-iphoneos/iosApp.app`.

## 3. Package into an .ipa

```bash
rm -rf /tmp/budgeyet-ipa
mkdir -p /tmp/budgeyet-ipa/Payload
cp -R build/DerivedData/Build/Products/Debug-iphoneos/iosApp.app /tmp/budgeyet-ipa/Payload/
mkdir -p build/release-artifacts
cd /tmp/budgeyet-ipa && zip -qry "$OLDPWD/build/release-artifacts/budgeyet.ipa" Payload/ && cd -
```

Final artifact: `frontend/build/release-artifacts/budgeyet.ipa`.

## 4. Install on the iPhone

1. AirDrop `budgeyet.ipa` to the iPhone.
2. Open **SideStore** on the phone → tap the IPA → **Install**.
3. If prompted: enable **Developer Mode** (Settings → Privacy & Security → Developer Mode) and trust the certificate (Settings → General → VPN & Device Management).

## Conventions / gotchas

- The `.ipa` is **unsigned by design** — never pass a signing identity. SideStore re-signs on-device.
- If you need a signed build for a dev device via Xcode (7-day free provisioning), use the Xcode UI with automatic signing instead — this skill is specifically the SideStore path.
- The app requires minimum iOS 17.0 (set via `IPHONEOS_DEPLOYMENT_TARGET` in `iosApp/iosApp.xcodeproj/project.pbxproj`).
- This is a Debug-configuration unsigned build for sideloading. For Store distribution you'd need a proper signing team — out of scope here.
